# ResearchPilot 浏览器智能精读（2026-10-05）

这一阶段在博客 `/research` 中新增中文模型问答、扫描 OCR、公式结构识别与辅助推导、按页全文翻译。Python v0.10 本机版未改动；这四项新流程在浏览器工作台中使用。

## 开始使用

1. 导入论文，在“智能精读 → 模型服务设置”选择“站点模型”并填写访问码，统一使用 GPT-6.1 Sol，由站长通过独立 OpenAI API 付费；启用条件与部署步骤见 [站点 API 说明](researchpilot-hosted-api.md)。也可选择自己的模型服务，填写服务地址（包括要求的 `/v1` 前缀）、文本模型、API 密钥，公式功能另填支持图片输入的视觉模型。
2. 点击“记住服务选项”。仅保存使用方式、地址与模型名称；访问码和自有密钥只保留在当前页面的内存中，不写入 localStorage、IndexedDB 或导出文件。刷新或离开工作台后需重新填写。
3. 核对接收服务，勾选发送许可，测试连接。站点模型通过同源 Vercel Function 调用固定 OpenAI Responses 接口，站长密钥只放服务端。自有模型采用兼容 Chat Completions 的接口，服务必须允许网页跨域访问（CORS）。网站没有无条件转发任意地址的公共代理。
4. 切换“中文问答”“扫描 OCR”“公式与推导”“全文翻译”。OCR 无需模型、密钥或发送许可。

请使用受信服务与适当的额度限制。网站同源脚本在运行期间可以接触用户填写的密钥，因此不提供长期保存密钥选项。地址或模型变更后，发送许可重置。浏览器直连模式不能保证所有服务商兼容，HTTP 错误、CORS、无效响应、输出截断均明确提示，不回显上游错误正文与密钥。

## 数据与模型行为

- 中文问答：模型将任意表述转换为最多 4 个英文检索表达，浏览器在所选页中搜索并融合结果，最多选择 20 段原文。模型再根据这些证据生成中文解释，保存原问题、英文表达、真实片段、PDF 页码与引用。回答只依据取回的片段，并非穷尽整篇全文。未知引用编号标为无效，没有有效引用时提示待核对；编号校验不等于事实蕴含验证。问题可自由用中文表达，不能保证任意问题都能回答。
- OCR：Tesseract.js 在浏览器工作线程运行，本站提供引擎与英文、简体中文语言数据，不使用运行期第三方 CDN。PDF 逐页渲染后识别；当前页先预览校对再保存，无文字页批量处理则逐页保存为待校对。保存更新检索片段，保留原 PDF、阅读位置与笔记；重新解析仍保留已保存 OCR 文字。空结果、超过单页 10 万字或全篇 100 万字不会保存；置信度不是准确率保证。图表与数学式不能依赖普通 OCR 保真。
- 公式：发送当前页 JPEG 与相邻页最多 1.2 万字上下文给视觉模型。结果含 LaTeX、符号表、结构、假设、逐步等式、检查与不确定事项。KaTeX 使用 `trust:false`、展开次数及尺寸限制，HTML 内容转义；不把模型输出当 HTML 执行。公式推导未经过计算机代数或形式化验证，无法识别的公式拒绝保存为有效结构。
- 翻译：按 PDF 实际页序、每段约 3500 字以内翻译，保存原文和中文对照，可选术语表。每段单独请求与持久化，失败即暂停，不自动重试产生费用。用论文哈希、页码/片段、原文、服务/模型、术语表及协议版本计算缓存键。相同内容继续时跳过已保存段，OCR 修正或配置改变产生新键。术语表和范围缓存在当前浏览器。缺文字页明确列为未完成；覆盖的是可提取正文，不包括所有图片内文字，不输出保留原版式的翻译 PDF。

所有模型请求都经过用户主动操作与许可，问答发送问题/检索证据，公式发送页面图片/相邻文本，全文翻译会逐段发送所选范围内全部可提取文字。识别或生成的结果会保存在同一浏览器中。取消会中断请求/识别并保留已保存片段；如果服务端已经接收请求，取消不能保证撤销其计费。关闭页面会停止任务，不在后台云端继续执行。

数据库从 v1 原地升级到 v2，新增 `results` 对象仓库；保留原有文件、笔记与阅读位置。每篇最多 2500 条模型结果，单条序列化上限 15 万字符。移除论文会同时移除该论文的 OCR 索引、问答、公式与译文。Markdown 预览可用于复制/导出，尚无整个浏览器库的可恢复备份。

## 验收记录与边界

- 30 项自动测试通过：请求协议/脱敏、取消前不发请求、结构响应/截断拒绝、中英检索与页码隔离、引用校验、公式字段、翻译缓存/完整分段、OCR 原子保存、数据删除隔离、v1 数据迁移等。模型测试使用受控响应。
- TypeScript 检查与生产构建通过。模型正文不作为 HTML 渲染，公式仅使用受限 KaTeX。
- 实际浏览器：文本模型连接、中文问答证据保存、公式图片请求和排版、Markdown 预览、刷新后结果恢复与密钥清除通过。本地受控接口明确标识为验收响应，不是模型能力评分。
- 实际浏览器真实 OCR：3 页纯图片 PDF 从 0 个片段变成 3 个片段；中文“损失函数”命中第 2 页识别出的英文句子。单页校对保存、批量识别、取消保留已有结果已验证。
- 翻译中途模拟 HTTP 429：第 1 段保留，继续时仅请求剩余两段；总 4 次翻译调用包含 1 次失败，没有重复翻译已完成段。
- 没有配置用户真实密钥，尚未用真实模型验证任意中文问题的解释质量、复杂公式识别/推导正确性或真实整篇论文译文质量。不得将接口测试当作这些效果已经验收。低质量扫描、复杂双栏、长论文、移动端大文件仍需更广泛测试。
