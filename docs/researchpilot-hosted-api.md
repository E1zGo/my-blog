# 站点模型：GPT-6.1 Sol 与访问码试用

2026-10-08。站长使用独立计费的 OpenAI API，为受邀访客提供论文精读。此模式不使用 ChatGPT Plus 订阅，不接收 ChatGPT 登录密码、Cookie 或订阅令牌。

## 部署与启用

Vercel 从仓库根目录的 `api/research-model.ts` 部署 Node.js Function；无需独立服务器。前端默认显示“站点模型”，旧用户已配置的自有模型选项保留。缺少配置时接口拒绝付费请求，本地阅读、检索与 OCR 继续可用。

已通过 Vercel 域名清单核实，正式域名 `www.e1zgo.top` 对应项目是 **my-blog1**（`prj_EhVlbp3BtACMXTtUyOOE6yZPK7rH`），不是同仓库的 `my-blog`。在 **my-blog1 → Settings → Environment Variables** 配置以下变量，选择 Production，再重新部署。不要使用 `VITE_` 前缀，不要把密钥写入代码、公开配置或聊天：

| 变量 | 值 |
| --- | --- |
| `OPENAI_API_KEY` | 独立 OpenAI API 项目的密钥，需有 Responses 和 `gpt-6.1-sol` 使用权限及可用额度 |
| `RESEARCH_ACCESS_CODE` | 随机生成的 16–128 位字母、数字、下划线或短横线，建议 32 位以上；仅向受邀试用者提供 |
| `RESEARCH_AI_ENABLED` | `true` 才允许付费请求；设为 `false` 并重新部署可关闭 |
| `RESEARCH_ALLOWED_ORIGINS` | 可选，逗号分隔的完整来源，默认 `https://www.e1zgo.top,https://e1zgo.top`；预览域名需显式添加 |

不要为其他关联 Vercel 项目、公共 PR 预览环境自动复制生产密钥。轮换访问码会使旧码失效，轮换密钥后同样需要重新部署。

访客导入论文后，在“智能精读 → 模型服务设置”选择站点模型，输入访问码并确认内容发送许可，点击“测试模型连接”。此测试会产生一条短 API 请求。访问码只保留在当前页面内存中，刷新或离开后清除；“记住服务选项”不会保存访问码。OCR 不需要访问码。

## 请求与费用边界

- 页面把问题、所选证据或一张公式页图片发送到本站 Vercel Function，服务端再发送到固定的 OpenAI Responses 地址。原 PDF 不整份上传；全文翻译逐段发送可提取文本。接口不主动写入论文、访问码和模型结果日志或数据库；结果仍保存在访客浏览器中。平台日志与 OpenAI 数据处理仍受各自服务规则约束。
- 站点模式固定 `gpt-6.1-sol`、`reasoning.effort=medium`、`store=false`、最多 12,000 个输出 token（含推理预算）；用户不能修改上游地址、模型、工具或输出上限。此路由不启用模型工具调用。
- 每次至多 80,000 文本字符、1 张 JPEG/PNG 内嵌图片，请求体最多 4,000,000 字节，图片 data URL 最多 3,500,000 字符。200 MB 是本地 PDF 导入限制，不是单次模型请求大小。
- 校验访问码与来源；拒绝远程图片 URL。访问码仅用于限制受邀试用，不是用户账号或个人配额。知晓访问码者仍可能绕过网页自行调用接口；来源校验也不能替代身份认证。
- 每个运行实例每分钟最多 12 次已认证请求、最多 2 个同时处理任务、最多 60 次认证尝试。**这些内存限制会随实例重启而重置，多个实例的额度独立，不是跨实例总量或金额硬上限。** 因此本阶段只适合小范围访问码试用；向公众开放前应接入持久化配额与独立用户身份。
- 不自动重试付费请求。失败、限流、超时或输出截断暂停任务并保留已保存片段；续译会跳过已保存片段。取消不能保证撤销上游已经接收的请求或费用。服务端超时为 100 秒，Vercel Function 时限 120 秒。
- 使用独立 API 项目监控用量，设置账户可用的费用控制与告警。不要把项目预算告警或上述实例限流描述成已实现的总费用硬上限。

## 验收范围

本阶段 40 项自动测试、TypeScript 检查与生产构建通过。浏览器受控接口验收覆盖错误访问码零上游调用、有效码连接、中文问答引用、页面图像公式处理、3 页分段翻译及刷新后凭据清空、历史结果保留。受控返回明确标注为合成内容，不是在线模型能力验收。发布时生产 API 尚未配置密钥，默认关闭。

自动测试覆盖无配置拒绝调用、访问码与来源校验、请求限制、固定模型与上游、密钥不转发到浏览器、响应/拒绝/截断、限流、并发与取消、客户端脱敏及原有论文流程。受控接口只用于验证协议，不代表真实模型质量。没有真实密钥时不能声称真实连接、账单或论文效果已经验证。
