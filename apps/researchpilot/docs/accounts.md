# v0.9 账号、项目权限与迁移

本版完成可选账号模式，仍只监听本机。默认 `RP_AUTH_MODE=local` 保持单人离线工作方式；`RP_MODE=offline` 控制模型，与是否登录无关。开启账号无需模型密钥。本版没有发布到公网。

## 启用已有数据的账号登录

1. 保存浏览器草稿，使用「自检与备份」下载并校验完整备份，然后停止服务。
2. 在项目目录的交互式 PowerShell 中执行以下命令，输入自己的密码两次。密码不会显示，也不放在命令行参数或 `.env` 中。

   ```powershell
   .\.venv\Scripts\python.exe -m researchpilot.accounts create-admin --username admin
   ```

3. 在项目根目录创建或编辑 `.env`，加入 `RP_AUTH_MODE=accounts`，保留现有 `RP_DATA_DIR`，再运行 `start.bat`。本机 HTTP 保持 `RP_COOKIE_SECURE=false`。
4. 打开工作台并登录。已有项目、原文件、历史任务、笔记和实验记录全部归属首次创建的管理员，ID 不变。

用户名为 3–40 个英文字母、数字、点、横线或下划线，以字母或数字开头，统一转为小写。密码为 15–128 个字符，允许空格和中文，不强制符号组合，也不去掉首尾空格。建议使用不在其他服务复用的长密码。

只有本机命令可以初始化管理员，网页没有开放的“第一个访问者成为管理员”入口。已有账号时再次初始化会被拒绝；误将配置改回 `local` 后，匿名业务访问会被拒绝，启动自检也会报错。修正 `.env` 并重启即可恢复登录，不要删除数据库。

## 邀请、停用和密码恢复

- 管理员在「账号与权限」生成邀请码，自行交给成员。邀请码只显示一次，24 小时内可注册一个普通成员账号；使用后或过期后失效。不存在公开注册或网页提升管理员权限。
- 成员登录后拥有自己的项目，不能查看或修改别人的论文、预览图、引用、报告、笔记、日志或实验记录。管理员的日常项目访问也受相同归属检查约束。
- 管理员可以停用或重新启用成员。停用立即删除该成员的登录会话，项目资料保留；重新启用后需要重新登录。管理员不能通过网页停用自己。
- 修改密码需要当前密码，成功后其他登录会话失效。登录有效期为 12 小时，不自动延长。退出登录使当前会话失效。
- 忘记密码时由有数据目录访问权限的本机维护者停止服务，在交互式终端执行：

  ```powershell
  .\.venv\Scripts\python.exe -m researchpilot.accounts reset-password --username admin
  ```

  该命令重设指定账号密码并删除其全部登录会话，不改角色、启用状态或项目归属。没有邮件找回功能。

## 草稿、备份与升级

本机单人模式继续使用原来的浏览器存储。账号模式的草稿、阅读位置和研究范围按用户保存在当前标签页的 `sessionStorage`，刷新可保留，退出账号、重新登录、切换账号会清除；关闭标签页也通常会清除。浏览器可能恢复之前的会话，不应把网页账号当作同一操作系统/浏览器配置内的磁盘加密措施。重要内容请点击保存写入项目，使用各自的操作系统账户和浏览器配置。

同一浏览器其他标签页切换账号或退出后会重新验证登录，并清除账号临时缓存。浏览器旧的单人草稿不会自动迁入账号空间；启用前应先正式保存。密码管理器可以填写登录表单。

账号模式下「自检与备份」只对管理员开放。**完整备份包含所有账号的项目资料、密码哈希和归属关系**，管理员有权获取这些数据；本应用不提供对管理员的加密隔离。下载包不会携带可恢复的登录会话、未使用邀请码或登录限流记录，恢复后每位成员需要重新登录，邀请需要重新生成。生成备份不会退出正在使用的账号。

v0.8 的无账号完整备份可继续校验和恢复；第一次初始化管理员时接管其中的项目。v0.9 含账号的备份恢复后须设置 `RP_AUTH_MODE=accounts`。恢复只允许写入新目录，禁止覆盖。不要使用不认识账号权限的旧应用版本打开启用账号后的数据库；回退需使用升级前备份。

## 实现与验收边界

- 密码使用随机盐和 scrypt（N=2^17、r=8、p=1），单次约 128 MiB 内存，全进程最多同时执行两次密码派生；数据库不保存明文密码。
- 登录令牌由 32 字节安全随机数生成；数据库仅存 SHA256 摘要。Cookie 使用 HttpOnly、SameSite=Strict、Path=/；本机 HTTP 默认不设 Secure。未来 HTTPS 部署必须启用 `RP_COOKIE_SECURE=true`，并另行配置可信代理和域名。
- 写操作校验同源来源与会话绑定的 CSRF 请求头。鉴权和项目权限在上传正文解析前完成；不依赖界面隐藏按钮。未登录返回 401，跨账号资源返回 404，普通成员访问管理入口返回 403。
- 登录按直接连接 IP 和用户名限制 15 分钟内尝试次数；修改密码和邀请码操作也有限流，状态持久保存在 SQLite。当前不信任 `X-Forwarded-For`，不适合直接套在未经配置的多用户反向代理后。
- 项目所属关系单独存表，避免改写已有论文、实验或任务结构。仍使用单进程、单 worker；多进程共享后台任务恢复机制尚未实现。

设计参考 OWASP 的 [密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)、[会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html) 和 [CSRF 防护](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)。自动测试不等于独立安全审计。公网试用仍需域名与 HTTPS、用户配额、隔离解析、网络和并发负载验收、持续备份与告警；真实大模型回答效果也未验收。
