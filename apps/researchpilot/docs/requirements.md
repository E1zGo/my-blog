# 软件需求规格说明书

版本：0.10 · 目标用户：AI/CV 科研初学者、准备科研项目展示的本科生。

本阶段增加账号用量、并发/空间限制、只读就绪探针、管理员运行状态与博客入口。真实服务部署依赖持久服务器、域名/HTTPS 和运维验收；当前不开放公共注册，详见 [部署说明](deployment.md)。

目标不是自动复现任意论文，而是提供可追溯的资料检索、代码理解和实验准备辅助。用户已明确选择先使用离线演示；所有生成式能力通过单独配置的模型接口提供。

## 数据与非功能约束

- 文档支持 PDF、UTF-8 TXT、Markdown 和 LOG；扫描 PDF 需事先 OCR。图片、压缩包和可执行文件不接受。
- 页面与代码片段可被检索不代表解析无误；用户可查看所有提取文本校验。
- 每个项目最多 5000 片段。单文件默认上限 200 MB，通过 RP_MAX_UPLOAD_MB 可配置为 1–512 MB；前端展示、预检和后端校验使用同一配置。上传过程和每份文件的失败原因持续展示。PDF 300 页。仓库只读最多 20 个白名单文本文件，每个 200 KB，优先 README 与依赖/入口。
- 工具不提供系统命令执行、任意文件读取或任意 URL 抓取；GitHub 固定域名、禁止重定向和 symlink 读取。
- 应用绑定本机。默认 local 为单人模式；accounts 提供登录、邀请与按账号校验的项目访问，管理员备份可包含所有账号资料。公网隔离与部署仍待验收。
- 秘钥由 `.env` 注入并忽略提交。模型错误不回显请求头、令牌或完整远端错误体。
- 最多 3 个任务并行工作、10 个排队/运行任务。取消会在下一工具/模型边界生效；阻塞模型请求最多等待其 60 秒超时。
- 工具轨迹是工具名、输入、状态与耗时，不展示或存储模型私有推理链。
- 每项目最多 1000 条研究笔记（含回收站）；正式笔记保存在 SQLite，未保存草稿仅在当前浏览器内保留，清除浏览器数据会影响草稿。用户分析与原文证据分开保存和导出。
- 每项目最多 500 条实验记录（含回收站）；单条最多 40 项参数、20 个有限数值指标、10 份日志，每份日志快照最多 20000 字符。状态由用户填写，服务重启不会改写；不自动执行或验证实验。
- 日志分析最多 50000 行、2000 个指标点、32 组序列，单行 4096 字符；缺少完整文本/原文件的旧日志需重传。来源确认值由服务端核对；单位、划分与协议由用户确认，不自动选出“最佳模型”。

## 不在本版范围

自动 shell/GPU 执行、多 Agent 协作、真实论文全面 benchmark、OCR、向量数据库集群、企业单点登录/组织协作、云端公网发布、GitHub 自动开源、自动下载数据集与模型权重。

P2 的执行器应作为独立隔离服务设计，增加资源配额、审批、网络/文件权限和结果采集；不能把当前只读工具直接改成任意 shell。
